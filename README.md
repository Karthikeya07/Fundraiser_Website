# FundRaiser - Donation Platform Website

A responsive and user-friendly fundraising platform designed to help support homeless children, animals, and elderly people in need. This website provides a trusted donation platform for people worldwide to contribute to various causes.

## Features

- **Multiple Donation Causes**: Support homeless children, animals, and elderly care
- **Responsive Design**: Mobile-friendly interface that works across all devices
- **Interactive Gallery**: Showcasing the impact of donations
- **Donation Statistics**: Real-time counters showing campaigns, donations, volunteers, and reviews
- **Contact Information**: Easy ways to reach out and get involved
- **User Reviews**: Testimonials from satisfied donors

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons
- Razorpay Payment Integration

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/Fundraiser_Website.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Fundraiser_Website
   ```

3. Open `index.html` in your web browser or use a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000

   # Using Node.js (http-server)
   npx http-server
   ```

4. Visit `http://localhost:8000` in your browser
